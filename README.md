## 🐇 Rabbitar Template

A clean, highly responsive landing page template built with detailed micro-interactions. No bloated code—just React, Tailwind CSS, and Framer Motion. It features 3D scroll effects, asymmetric overflow clipping, and a global dark mode toggle that doesn't break your mobile layout.

---

## 📌 Project Overview

- **Built** a SaaS landing page focused on fluid micro-interactions.
- **Designed** a complex Bento-Grid with eye-catching animations.
- **Engineered** 3D-perspective hero images and gradients without triggering horizontal scrollbars.
- **Implemented** a seamless global dark mode toggle.
- **Developed** a fully responsive, auto-scaling pricing grid.
- **Created** a dynamic footer section with a 3D gradient effect.

This project takes standard React components, Tailwind CSS, and Framer Motion, and wires them together into a production-ready template.

---

## 🛠️ Tech Stack

- **Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Fonts:** Manrope & Inter
- **Routing:** React Router
- **Icons:** Tabler Icons & Lucide React
- **Version Control:** Git & GitHub
